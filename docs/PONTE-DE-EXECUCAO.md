# Ponte de execução

## Núcleo e projeto

O núcleo guarda métodos e templates. Cada projeto guarda seu briefing, memória, identidade, artefatos e progresso. Os comandos attach e bootstrap são complementares: attach instala a ligação; bootstrap copia apenas arquivos ausentes do esqueleto. new faz ambos. Nunca sobrescrever memória existente para aplicar um template.

## Fontes e ferramentas

A variável CLAUDE_PLUGIN_ROOT nas especialidades de negócio deve ser resolvida como vendor/mazyos-official no núcleo. Não é preciso alterar variável global. Os comandos /mazyos:nome são aliases de mazyos-nome em catalog.json; chamadas Expx resolvem para os adaptadores expx-nome. Leia as fontes e use ferramentas equivalentes disponíveis.

O mod TypeScript, painel, status e hooks do plugin original não são executados no Codex/Orca. A leitura de memória é responsabilidade explícita do orquestrador. Não alegar carregamento automático ou bloqueios técnicos inexistentes. A extensão VS Code é preservada como fonte e não foi instalada.

## Combinação dos métodos

Para lançamento, valide oferta e público, depois produza copy, implemente a página, prepare campanha e rastreamento, e faça revisão cruzada. Para sistema, trabalhe arquitetura e features com evidência técnica. Para conteúdo, use memória e identidade antes de produzir; revisão fecha o ciclo. As bibliotecas locais de revisão e vendas complementam as especialidades oficiais.

O fluxo define entregas e handoffs, não multiplica automaticamente agentes. N inclui o orquestrador. Para três: coordenação, execução e revisão independente. Com menos de três, declare a ausência de revisão independente quando o mesmo agente implementar e revisar. Com mais executores, divida arquivos e declare dependências.

## Autonomia

Escolhas reversíveis no escopo podem prosseguir. Preferências e autorizações já dadas não precisam ser perguntadas novamente. Publicação, mensagens e mudanças externas obedecem ao pedido efetivo. A existência de uma skill de publicação não autoriza seu uso para enviar. Preserve as instruções do ambiente e do projeto.

## Medir resultados

Defina antes o que conta como entrega aceita: teste de comportamento, revisão visual, métricas calculadas ou pacote de campanha validado. Não prometa vendas, lucro ou conversão. Registre indicador, ponto de partida quando houver e como medir depois.
